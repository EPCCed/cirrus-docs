# ARCHER2 - Cirrus project migration 2026

!!! important
    This information was last updated on 8 Sep 2026.

This section of the documentation is a guide on the migration process for 
projects migrating from the [ARCHER2 National Supercomputing Service](https://www.archer2.ac.uk)
to Cirrus NCR.

More information is available on the following pages

   - [Migrating your account to Cirrus NCR](account-migration.md), includes:
      + Checking if your project/account will migrate to Cirrus NCR
      + Checking how much resource you will have on Cirrus NCR
      + How to setup your account on Cirrus NCR
   - [Migrating data to Cirrus NCR](data-migration.md), includes:
      + Links to information on how to transfer data to Cirrus NCR
   - [Main differences between ARCHER2 and Cirrus NCR](cirrus-differences.md), includes:
      + Summary of hardware differences
      + Summary of software differences


!!! tip
    If you need help or have questions on this migration process, 
    please [contact the Cirrus service desk](https://www.cirrus.ac.uk/support-access/user-support/)
